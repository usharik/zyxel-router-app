# Фикстуры реального роутера (санитизированы)

Сняты с VMG8623-T50B через `macos/.build/debug/routercapture` 2026-11-08. Значения обезличены:
пароли Wi-Fi → `<redacted>`, MAC/SSID/IP/имена заменены с сохранением ФОРМАТА (разделители, длина, тип).
Структура и типы полей — настоящие, на них строятся тесты разбора.

- `cardpage_status.json`, `lanhosts.json` — обзор и устройства.
- `paren_ctl_with_profile.json` — родительский контроль с одним профилем (снят в момент обратимого теста записи).
  Подтверждает реальный формат: `Days` возвращается СТРОКОЙ ("Mon"), `MACAddressList` с двоеточиями,
  `TimeRangeList` вида "09:00-10:00", роутер сам добавляет `ScheduleRuleList`. Предел профилей = 12.
- `rip.json` (5 интерфейсов), пустые `static_route`/`dns_route`/`policy_route`.

Копии нужных файлов лежат в `android/app/src/test/resources/real/` для JVM-тестов.
